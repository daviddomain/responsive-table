Responsive Table

A lightweight web component that turns regular HTML tables into a mobile-friendly stacked layout. It keeps the original table markup, adds row labels on small viewports, and can optionally collapse rows for denser responsive views.

Usage

Wrap any semantic <table> in <responsive-table>. The component switches to the stacked responsive layout once its own width drops below the provided breakpoint. 

npm install responsive-table
import 'responsive-table';
// Now you can use <responsive-table> in HTML
<responsive-table
  breakpoint="800"
  collapsible
>
  <table>
    ...
  </table>
</responsive-table>

Attributes

The component intentionally keeps the API small. The wrapped table remains standard HTML, so most customization happens in your table markup and surrounding CSS.

Attribute Description
breakpoint Width threshold in pixels at which the component switches to the stacked responsive layout. Defaults to 768.
collapsible Optional boolean attribute. When present, each responsive row can be expanded or collapsed with a dedicated toggle button.

Notes

The idea for the stacked mobile table layout is inspired by the CSS- Tricks article Responsive Data Tables by Chris Coyier. This component packages that idea as a reusable web component with optional collapsible row behavior.

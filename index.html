Responsive Table

A tiny web component (custom element) that renders an animated sunrise with horizon and reflection. Colors and width are fully customizable.

Demo

Usage

npm install responsive-table
import 'responsive-table';
// Now you can use <responsive-table> in HTML
<responsive-table
  prop="400px"
></responsive-table>

Attributes

Property Description
Prop: Prop description, e.g., 400px
